# Genshin Impact transcription glossary -- current through v7.0 "Everwinter
# Without Mercy" (2026-08-12, Snezhnaya). Use with:  refire make ... --terms genshin.txt

# Ordering is deliberate: whisper's hotword prompt is capped by its 448-token
# window and faster-whisper keeps the TAIL of an over-long list, so character
# names -- the ones that actually get mangled -- sit at the bottom. Everything in
# this file still feeds the post-decode snap pass in full, cap or no cap.
#
# Only proper nouns belong here. An ordinary English word in this list can pull a
# near-miss real word onto it ("dream" -> "Dreams"), so no artifact set names, no
# "Golden"/"Nighttime"/"Memories".
